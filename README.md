# 🔍 مهندس تحليل الأعمال والمنافسين
## Market & Competitor Intelligence Specialist — ASAAS AI

نظام ذكاء تنافسي متكامل وذاتي القيادة مبني بأحدث معايير **منظومة أساس (ASAAS AI)**. يأخذ رابط أي موقع إلكتروني أو نصوصه المسحوبة، ليقوم بفهم الخدمات والجمهور ونموذج التسعير، ثم يبحث تلقائياً في الويب (عبر **Tavily API** ومحرك البحث الاستدلالي) عن أبرز 3 منافسين حقيقيين، ويُخرج مصفوفة مقارنة متعددة الأبعاد، تحليلاً رباعياً (SWOT)، ورصداً دقيقاً للفجوات التنافسية مع خارطة توصيات تنفيذية.

### 1. الوكيل الفرعي ①: محلل المحتوى (Content Analyzer)
- قراءة وسحب نصوص الموقع وتحليل هيكله (عناوين، فقرات، روابط، بيانات وصفية).
- تحديد دقيق لـ:
  - **ما هي خدمات الموقع؟** (قائمة مفصلة بالميزات وتلميحات الأسعار).
  - **من هو جمهوره المستهدف؟** (توصيف دقيق للشريحة السوقية).
  - **ما هي رسالته التسويقية وقيمته المقترحة؟** (Value Proposition).
  - **ما هي أسعاره ونموذج الفوترة؟** (إن وجدت في الموقع أو استدلالها).

### 2. الوكيل الفرعي ②: باحث المنافسين (Competitor Finder)
- صياغة استعلامات بحث ذكية وربطها بأداة **Tavily API** للبحث الفوري في الويب.
- البحث التلقائي عن أبرز **3 منافسين حقيقيين** في نفس المجال والنطاق الجغرافي.
- سحب ملخص خدمات وأسعار ونقاط قوة وضعف وتواجد المنافسين الرقمي.

### 3. الوكيل الفرعي ③: المحلل الاستراتيجي والمقارن (Strategic Analyst)
- **جدول المقارنة التنافسي المباشر:** مقارنة تفصيلية عبر 8 أبعاد جوهرية (الخدمات، الجمهور، التسعير، الرسالة، نقاط القوة، نقاط الضعف، التواجد الرقمي، الميزة الجوهرية) مع حكم استراتيجي لكل محور.
- **مصفوفة SWOT الرباعية:** نقاط القوة والضعف الداخلية، والفرص والتهديدات الخارجية.
- **تحليل الفجوات (Gap Analysis):** رصد فجوات الخدمات، فجوات التسويق، فجوات التسعير، وفجوات التقنية وتجربة المستخدم.
- **خارطة التوصيات الاستراتيجية:** توصيات مرتبة حسب الأولوية (عاجل، مهم، تحسين) مع قياس الأثر والجهد وخطوات التنفيذ العملية.

### 4. الهوية البصرية لمنظومة أساس (ASAAS UI)
- خطوط **ثمانية (Thmanyah Typeface)**: Sans للواجهة والأرقام، Serif Display للعناوين، Serif Text للفقرات.
- رموز الألوان الرسمية: Ink (`#221f1f`)، Gold (`#ba9555`)، Sand (`#d3c6b4`)، Clay (`#c3ad8d`)، Cream (`#ede7da`)، Paper (`#fcf9f5`).
- أسطح زجاجية سائلة (Liquid Glass) مع خلفية الهالات المضيئة (Ambient Orbs).
- دمج وضعيات ثلاثية الأبعاد لشخصية **روبوت أساس**.
- مساعد ذكي عائم (Assistant Widget) يجيب عن أي استفسار حول التقرير والمنافسين.

## 🚀 التشغيل السريع (Quick Start)

### الطريقة الأولى: بنقرة واحدة (Windows)
فقط قم بالنقر المزدوج على ملف:
```
run.bat
```
أو عبر PowerShell:
```powershell
.\run.ps1
```
سيقوم السكربت تلقائياً بتثبيت المتطلبات، بناء الواجهة، وتشغيل الخادم وفتح المتصفح على: `http://localhost:8000`.

---

### الطريقة الثانية: التشغيل اليدوي خطوة بخطوة

#### 1. تجهيز الخادم الخلفي (Backend)
```bash
# إنشاء البيئة الافتراضية
python -m venv venv

# تفعيل البيئة (Windows)
.\venv\Scripts\activate

# تثبيت المتطلبات
pip install -r requirements.txt

# تشغيل الخادم
python main.py
```

#### 2. بناء أو تشغيل الواجهة الأمامية (Frontend)
```bash
cd frontend

# تثبيت حزم الواجهة
npm install

# بناء نسخة الإنتاج (Production Build)
node ./node_modules/vite/bin/vite.js build

# أو تشغيل وضع التطوير الحي (Dev Server)
node ./node_modules/vite/bin/vite.js
```

## 🔑 إعداد مفاتيح الـ API (اختياري)

النظام مصمم ليعمل بكفاءة عالية وفورية حتى بدون مفاتيح API عبر محركه الاستدلالي المدمج، ولكن للحصول على نتائج حية من الويب ونماذج اللغة التوليدية:

1. انسخ ملف `.env.example` إلى `.env`:
   ```bash
   copy .env.example .env
   ```
2. أضف مفاتيحك:
   - `TAVILY_API_KEY`: احصل عليه مجاناً من [tavily.com](https://tavily.com).
   - `OPENROUTER_API_KEY`: من [openrouter.ai](https://openrouter.ai) أو `GEMINI_API_KEY` من [Google AI Studio](https://aistudio.google.com).
3. يمكنك أيضاً إدخال المفاتيح وتعديلها مباشرة من داخل لوحة التحكم عبر زر **«مفاتيح الـ API»**.

## 📡 واجهات الـ API المتاحة (REST Endpoints)

| المسار | الطريقة | الوصف |
|---|---|---|
| `POST /api/analyze/url` | POST | تحليل موقع عبر الرابط والبحث التلقائي عن 3 منافسين |
| `POST /api/analyze/text` | POST | تحليل محتوى مدخل يدوياً ومقارنته بالمنافسين |
| `GET /api/reports` | GET | استرجاع ملخصات جميع التقارير المحفوظة في قاعدة البيانات |
| `GET /api/reports/{id}` | GET | تفاصيل تقرير تنافسي كامل بصيغة JSON |
| `GET /api/reports/{id}/html` | GET | تصدير التقرير كصفحة HTML تفاعلية فخمة بهوية أساس |
| `GET /api/reports/{id}/markdown` | GET | تحميل التقرير كملف Markdown منسق |
| `DELETE /api/reports/{id}` | DELETE | حذف تقرير محدد من قاعدة البيانات |
| `GET /api/status` | GET | فحص حالة النظام والمفاتيح المفعلة |
| `GET /docs` | GET | توثيق تفاعلي كامل عبر Swagger UI |
